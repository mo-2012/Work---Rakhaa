# مستحقات العمالة — رخاء

نفس موقفك الأصلي (نفس التصميم والحسابات والبيانات) بعد تنظيمه في ملفات، وإضافات جديدة:

- **تبويب «إدخال»:** تسجّل ورديات (أسماء كتير مرة واحدة)، دفعات (اللي خده الفرد)، تحصيل من مصنع، ومصروفات. فيه تعبئة تلقائية للأجر والفوترة من آخر وردية لنفس المصنع، وزرار تراجع.
- **حاسبة الحساب** جوه كشف كل فرد: خد إيه حسب النوع، وتكتب مبلغ تشوف المتبقي بعده، وتسجّل سلفة أو تصفية بضغطة.
- **موقف الشركة** في الصفحة الأولى: الشركة عليها كام، ليها كام، الصافي، الهامش، المصروفات، صافي الربح (البنات + الشباب).
- **تصدير Excel** بنفس شكل الرفع، فتقدر تعمل نسخة احتياطية وترجّعها.

## الملفات
```
index.html              الصفحة
assets/css/style.css    التصميم
assets/js/data.js       بيانات البداية + تعريف القسمين
assets/js/app.js        الموقع الأصلي (الملخص / الأفراد / المصانع / السجل)
assets/js/extras.js     الإضافات الجديدة (لازم يتحمّل آخر واحد)
excel/                  ملفين Excel ببيانات البنات والشباب الحالية (ارفعهم من زرار الرفع)
database/schema.sql     مخطط Supabase اختياري للمرحلة الجاية
database/seed.json      البيانات الأصلية JSON
```

## التشغيل
ارفع كل الملفات (بنفس الفولدرات) على الاستضافة، أو افتح `index.html` مباشرة. الموقع محتاج إنترنت لتحميل Chart.js و SheetJS والخط من CDN.

## ملاحظات مهمة
- البيانات اللي بتدخلها بتتخزن **في متصفح كل جهاز** (زي رفع Excel الأصلي). مش مشتركة بين الأجهزة لحد ما نربطها بقاعدة بيانات.
- زرار «استرجاع البيانات الأصلية» في الملخص بيمسح اللي أدخلته ويرجّع بيانات `data.js`. صدّر Excel قبله.
- الأرقام في كشف الفرد بتتبع فلتر الفترة المختارة، فاختار «كل الفترة» لما تسجّل دفعات.
