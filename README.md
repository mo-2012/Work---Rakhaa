# مستحقات العمالة

نفس الموقع الأصلي بالظبط، متقسّم لملفات منفصلة (من غير أي تغيير في الشكل أو الوظايف).

## الملفات
- `index.html` : الصفحة الرئيسية
- `assets/css/style.css` : كل التصميم
- `assets/js/data.js` : البيانات الأصلية (البنات / الشباب) وتعريف المجموعتين
- `assets/js/app.js` : منطق الموقع (الحسابات، الرسوم، السجل، قراءة الإكسيل، مشاركة واتساب)
- `database/seed.json` : نفس بيانات `data.js` بصيغة JSON
- `excel/البنات.xlsx` و `excel/الشباب.xlsx` : البيانات بنفس شكل الشيتات اللي الموقع بيقرأها (الورديات / المدفوعات / المتحصلات / مصروفات أخرى)، تقدر تعدّل فيها وترفعها من الموقع

## التشغيل
افتح `index.html` في المتصفح مباشرة. محتاج إنترنت للخط ومكتبتي Chart.js و SheetJS (بيتحملوا من CDN).
البيانات اللي بترفعها بتتحفظ في المتصفح (localStorage) بمفتاح `wd_f` و `wd_m`.

## النشر
ارفع المجلد كله كما هو على أي استضافة ثابتة (GitHub Pages / Netlify / Cloudflare Pages).

## الإضافات (النسخة المطوّرة)
- `assets/js/extras.js` : تبويب **إدخال** (وردية / دفعة لعامل / تحصيل من مصنع / مصروف) مع حفظ تلقائي في المتصفح والتراجع عن آخر الإدخالات.
- **حاسبة العامل**: مستحق كام، اتدفع له كام، الباقي، وزرار تصفية كاملة.
- **موقف الشركة**: عليها للعمال، ليها عند المصانع، المصروفات، والصافي (في الرئيسية وصفحة الاختيار وتبويب الإدخال).
- زرار **تصدير Excel** بنفس شكل الاستيراد.
- ملحوظة: البيانات محفوظة في متصفح كل جهاز (مش مشتركة بين الأجهزة). التصدير هو النسخة الاحتياطية.
